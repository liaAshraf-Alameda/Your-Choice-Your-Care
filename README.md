# Your-Choice-Your-Care — لعبة تفاعلية عن رعاية المريض المركزية

وصف:
لعبة صفحة واحدة (HTML/JS) تعرض 4 حالات لمرضى بأمراض غير معدية (سكري، أمراض قلبية، مرض كلوي مزمن، صرع). لكل حالة 3 جولات، وفي كل جولة 3 قضايا، كل قضية 3 خيارات: متمحور بالمريض، جزئي، وخيارات سيئة. اللعبة تستقبل تصويت الجمهور وتظهر النتائج مع عواقب واقعية وتأكيد على المشاركة في القرار واحترام تفضيلات المريض.

كيفية التشغيل:
1. انسخ الملفات (index.html, style.css, app.js, README.md) إلى مجلد.
2. افتح `index.html` في متصفح حديث (Chrome/Firefox).
3. املأ اسم المصوّت (اختياري) ثم ابدأ اللعبة.
4. في كل سؤال اختَر إجابة ثم اضغط "أرسل الأصوات" لعرض النتيجة والمتابعة.

ملاحظات:
- التطبيق يعمل محليًا بدون خادم. الأصوات تُحفظ في الذاكرة أثناء الجلسة فقط.
- يمكن تطوير نسخة متعددة المستخدمين باستخدام قاعدة بيانات وخادم (مثلاً Node.js + WebSocket) لالتصويت الجماعي عبر الشبكة.

لو عايز أرفع الملفات على المستودع اللي بعتهولي (https://github.com/liaAshraf-Alameda/Your-Choice-Your-Care)، اكتب "ارفعها" وأنا أتحقق من المستودع وأعمل commit/PR حسب رغبتك.
